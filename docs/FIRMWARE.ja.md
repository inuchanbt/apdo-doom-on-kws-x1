# ファームウェア公開・リスク・純正OTAでの更新

[English](FIRMWARE.md) · [日本語](FIRMWARE.ja.md)

**KOWSI KWS-X1向けの非公式・実験用ゲームファームウェア**です。確認したのは **Bootloader V1.1の実機1台**です。計測器のアプリを置き換えるため、ダウンロード・更新前に以下を読んでください。

## 版の選択

| リリース | ファイル | プレイ中に必要なもの |
| --- | --- | --- |
| [PC接続ワイドE1M1 v7r2](https://github.com/inuchanbt/apdo-doom-on-kws-x1/releases/tag/pc-wide-v7r2) | `kws-x1-doom-wide-v7r2.X1C` | データ対応USB接続と、動作中のPC素材・操作サーバー。 |
| [完全単体ワイドミニ v3](https://github.com/inuchanbt/apdo-doom-on-kws-x1/releases/tag/standalone-wide-v3) | `kws-x1-mini-wide-v3.X1C` | 電源だけ。素材は本体内蔵。敵2体の小型専用マップで、Web操作はありません。 |

どちらも240×135液晶全体を使い、自然な比率で横の画角を約106度に広げます。音声・セーブ・対応済みのマップ遷移はありません。確認台数が限られるため、**プレリリース**として公開します。

起動時にはオリジナルのFreedoom Phase 1ロゴを216×50で中央に1.2秒以上表示します。PC版はサーバー接続待ちの間もロゴを残します。ロゴ素材は内蔵し、追加フレームバッファーやプレイ中の処理は不要です。

## 起こりうるリスク・未確認の範囲

- **起動不能になる可能性があります。** 間違ったファイル、異なる機器・ローダー、更新中の電源断やUSB異常、初回起動時のフラッシュ書き込み異常で起動しなくなる場合があります。ローダー領域を意図した書き込み範囲から外していても、復旧は保証できません。外部書き込み器や修理が必要になる可能性があります。
- **純正へ戻す実機検証はしていません。** 更新前に自分の機器に適合する純正ファームを確保してください。ローダー・校正値・設定の完全バックアップは取得していません。領域を保護する設計と、それらを復元できることは別です。他個体の校正値やローダーダンプを流用しないでください。
- **通常のUSB電力計としては使えなくなります。** 計測・PD/QC制御・純正アプリの保護機能は提供しません。電気的な挙動、通過接続、負荷や充電器との適合性は検証していません。実験中は必要な電源・データ接続だけにし、他の端子や下流の機器は接続しないでください。本体・接続機器・充電器・ケーブルが損傷する可能性があります。
- **ゲームが停止する場合があります。** PC版は素材サーバーやUSB通信が止まると停止し、サーバー再起動と本体の電源入れ直しが必要です。単体版にPCは不要ですが、どちらもフリーズ・表示異常・長時間使用時の不具合が起こりえます。更新成功は安定性や電気的安全性の認証ではありません。
- **無保証・自己責任での使用です。** メーカー公認のファームではありません。保証やサポートの対象に影響する可能性があります。Bootloader V1.1の1台での動作確認は、他リビジョンや名前の似た機種への対応を保証しません。

## ダウンロード・照合

選んだリリースから `.X1C`、`SHA256SUMS`、英日説明書、ライセンス表記、`corresponding-source.zip`を取得してください。PC版では`pc-runtime.zip`も必要です。対応するE1M1素材とPython操作サーバーが入り、コンパイラーは不要です。Python 3.12を用意し、展開先で`python -m pip install -r requirements.txt`を実行した後、`./scripts/play.ps1`で起動します。

PowerShellでハッシュを計算し、そのリリースの`SHA256SUMS`と照合してください。

```powershell
Get-FileHash -LiteralPath .\kws-x1-doom-wide-v7r2.X1C -Algorithm SHA256
# 単体版は kws-x1-mini-wide-v3.X1C に置き換えます。
```

チェックサムでダウンロード後の変更は検出できますが、安全性や適合性を証明するものではありません。

## メーカーのWindows用OTAツールで更新

手元の **`KWS-X1 OTA 英文版.exe`** を使います。画面タイトルは **KWS-X1 OTA Tool V1.0**です。メーカー製ツールと純正ファームは再配布しません。ファイル名だけでは真正性を確認できないため、信頼できる入手先を利用してください。

1. ゲームの素材・操作サーバーと、他のUSBツールを停止します。接続するKWS-X1は1台だけにします。
2. 本体を抜き、**Back＋OK**を押しながら、ハブを使わずデータ対応USBケーブルで**PCへ直接接続**します。本体画面の **Bootloader V1.1** を確認します。今回のPC版はハブ経由の試行で最終照合に失敗し、ユーザーが直結へ変えた後、同じファイルで更新成功しました。ハブだけが原因と断定する検証や、すべての直結構成での動作保証ではありません。
3. OTAツールを開き、`Connected to KWS-X1!`、`KWS-X1:Entered OTA mode!`を待ちます。
4. 左のファイル選択ボタン（英語版でも`浏览文件`と表示）で、照合済みの`.X1C`を選びます。ファイル名とサイズを確認します。
5. 右の送信ボタン`发送文件`を押します。書き込み中と、上位アプリ領域を展開する**初回起動中も電源・USBを抜かないでください**。最終的な`Upgrade successful!`と`KWS-X1:Write completed.Restart!`を待ち、成功ダイアログを閉じます。途中の進捗表示だけで成功と判断しないでください。
6. PC版は`./scripts/play.ps1`を起動し、プレイ中も動かし続けます。単体版はゲーム画面が出るまで待てば、その後は電源だけの接続で動作します。

タイムアウトや検証エラーのまま最終成功表示に至らない場合は、完了と見なさないでください。ログを保存し、送信が止まるまで待ってから、適合するファイルで元のローダーからの復旧を試みます。確実に復旧できる手順はありません。領域構成と別の開発用書き込みツールの手順は[RECOVERY.md](RECOVERY.md)を参照してください（英語）。
